Огляд: що підготувати

Компоненти та оснастка

  • Зібрана плата BP5S rev1 зі штатним R1 = 10 мОм.
  • 5 резисторів 220 Ом, ≥0,25 Вт, для простого імітатора 5S.
  • Резистор навантаження 5 кОм, ≥0,25 Вт.
  • Резистори для TH1: 10 кОм (норма), 4,3 кОм (OTC), 2,2 кОм (OTD), 33 кОм (UTC), 56 кОм (UTD).
  • Окремий тестовий зразок плати й сумісний R1 = 100 мОм для тесту OCP на меншому струмі.
  • Ізольовані проводи, затискачі й відповідні роз’єми J3/J6; ізоляційна підкладка та щупи з тонкими наконечниками.

Обладнання

  • Лабораторне джерело 0–22 В з обмеженням струму для базових тестів.
  • Незалежний 5S емулятор комірок із вимірюванням струму кожного каналу та здатністю поглинати ≥0,5 А/канал для заряду й балансування.
  • Зарядний CC/CV прилад до 20 В і 0,3 А, захищений від напруги на вимкненому виході.
  • Мультиметр; другий мультиметр або логер для одночасного виміру струму й напруги.
  • Диференціальний вимірювач або ізольований осцилограф/логер для імпульсів балансування на R7.
  • Електронне навантаження CC з імпульсним режимом ≥0,8 А; 4-провідний омметр для R1.
  • Для штатного OCP: окремий кваліфікований імпульсний стенд, вимірювач температури Q1/Q2/R1 і підтверджена струмова межа плати.

Базові кейси потребують простого імітатора. Резистори на TH1 відтворюють електричний сигнал NTC, а не фактичну температуру плати.

Вигляд зверху. Для J3 порядок згори вниз: 4S, 3S, 2S, 1S. Для J6 верхній контакт — PACK+, нижній — PACK−. Перед живленням перевірте фізичний виріб.
