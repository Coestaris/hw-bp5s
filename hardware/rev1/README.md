# BP5S revision 1

Manufactured five-series-cell battery protection board. The active design uses a BQ7791500PWR protection controller and a CSD18534Q5A power MOSFET pair, with cell-sense filtering, temperature sensing, and an XT60 pack connection.

Open [bp5s.kicad_pro](bp5s.kicad_pro) in KiCad 10. The local symbol and footprint libraries are included alongside the project; shared component models and datasheets are included in [assets](../../assets/).

See the [project overview](../../README.md) for architecture and release downloads, and the [test plan](test-plan.html) for bring-up checks.
